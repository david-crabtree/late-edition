# Bundled fonts

The newsroom interface loads its three typefaces from this folder rather than from Google Fonts, so launching the app makes no network requests. Each file is the Latin-subset WOFF2 as served by fonts.googleapis.com; the UI is English, so no other subsets are shipped. All three are licensed under the SIL Open Font License 1.1 (see `LICENSE-OFL.txt`).
